角色颜色：🟨 用户🟪 网页🟦 Forma 后端🟩 GLM🟥 Seedream

后端的规则会自动理解同义句吗？

不会。规则是固定条件，未写到的表达可能漏判。当前特定前置处理包括：确认已有草案的候选判断、窄范围的已确认方案直读、明确禁止生图的限制、九宫格裁切和继续未完成计划。一般语义请求交给 Planning GLM。

后端会把什么发给 GLM？

Planning GLM 收到规划 System Prompt、本轮用户话语、后端选出的相关任务与方案快照、约束、素材信息及可用图片。Agent GLM 另外收到执行 System Prompt、任务 Context、部分相关聊天历史和本轮可用工具。Seedream 收到的是最终生图 Prompt 与参考图片参数。

所有 Context 都由后端管理吗？

Forma 后端保存用户消息、图片、方案版本、确认状态、素材和画布，并为每一次 GLM 调用选择输入。GLM 不会自行读取网页或项目数据库；它只知道本次请求带给它的内容，然后向后端返回文字或工具调用建议。

这次失败卡在哪里？

后端已找到已确认 v2，但窄范围直读规则没认出“最后定下来的／不用做任何调整”，因此发给 Planning GLM。主模型 HTTP 429“访问量过大”；备用请求在发送前被 Forma 本地预算拦住。没有进入 Agent，也没有调用 Seedream。
